## Data & licensing posture

- Transcript text: short verbatim excerpts (~300 chars) indexed from public
  YouTube captions on the credited channel; every result deep-links to the
  exact moment in the source video. Caption ownership stays with the channel —
  this is an attributed excerpt index.
- Embeddings: `BAAI/bge-small-en-v1.5` (MIT) via `@huggingface/transformers`
  (Apache-2.0), int8-quantized in `emb.bin`.
- Captions fetched with `yt-dlp` (Unlicense).
